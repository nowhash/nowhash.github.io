How I Used Agentic AI to Redesign My Entire Website

“This was my first serious attempt at using an agentic AI tool for a relatively large coding project. One thing I realized is that using agentic AI is not simply about writing a prompt and waiting for the code to appear.”

Over the last few days, I have been exploring agentic AI and how to use it in different contexts. Although I have previously used different AI models, such as ChatGPT, Claude, and Gemini, for various tasks, I had never used agentic AI for coding or development. As people say, better late than never! I decided to explore agentic AI.

Previously, I had a personal website hosted on GitHub Pages. It was built with Astro and had a few basic features, such as blog posts and publications.

I was using a customized version of the Astro Storyteller theme developed by Hasin Hayder. I had modified it to create a simplified personal portfolio website.

Later, I started thinking about extending it from a minimal personal portfolio into a more complete and robust personal archive. I wanted to use the website to publish not only research-related content but also tutorials, essays, travel stories, daily experiences, teaching materials, and other things.

With that in mind, I decided to use agentic AI to help develop and redesign my website.

Tools and Models I Used

Here are the tools and models I have used so far:

  • ChatGPT and Gemini: For planning, brainstorming, and preparing prompts.
  • OpenCode: As the agentic coding environment.
  • DeepSeek V4.1 Flash: The free model available through OpenCode.
  • DeepSeek V4.1 Flash 1017 (InferX): Another model endpoint I experimented with through InferX.

These are the tools I used throughout the process.

How I Approached the Redesign

1. Creating a Separate Git Branch

First, I created a new branch in my existing website repository. I wanted to keep the current working website untouched while experimenting with the redesign.

Then, I initialized OpenCode on that branch.

2. Preparing the Requirements and Design References

I created a project in ChatGPT and shared my existing website along with a list of features I wanted to introduce.

I also used Gemini to generate an image that illustrated the type of design I wanted for my website. Having a visual reference made it easier to communicate my design preferences.

Then, I provided the generated image and the list of features to ChatGPT and asked it to prepare a prompt for OpenCode.

Once I received the prompt, I reviewed it and made the necessary changes before providing it to the DeepSeek model.

3. Taking a Step-by-Step Approach

Instead of asking the model to redesign the entire website at once, I adopted a step-by-step procedural method.

First, I asked DeepSeek to analyze the existing project and understand its structure. Then, I asked it to prepare a plan for implementing the changes I wanted.

After reviewing the plan, I started asking the agent to implement the changes gradually.

I found this approach more manageable than asking the agent to modify everything at once. It also allowed me to review the implementation at different stages and identify problems before moving to the next task.

4. Refining the Implementation Through Multiple Iterations

After the initial implementation, I started reviewing the website and identifying things that needed to be changed or improved. Sometimes, the output was not exactly what I had in mind. In those cases, I explained the issues and provided additional instructions.

I also used ChatGPT throughout this process to prepare and refine prompts for OpenCode. Whenever I wanted to make a particular change, I described what I wanted to achieve and asked ChatGPT to turn it into a clear instruction. I then reviewed the prompt, made the necessary adjustments, and provided it to the coding agent.

This became an iterative process. I would review the changes, identify what was missing or not working as expected, and ask the agent to make further modifications. Rather than trying to get everything right in the first attempt, I gradually developed the website through multiple rounds of instructions and revisions.

5. Managing Changes with Git

Since I was working on an existing website, I wanted to make sure that the original version remained safe.

Working on a separate Git branch helped me manage the changes without affecting the main branch. I could review the modifications, keep track of new files, and make corrections whenever necessary.

Once the redesign was complete, I committed the changes to my working branch and merged it with the main branch.

This was particularly useful because the redesign involved changes to many parts of the project, including components, page layouts, content collections, navigation, configuration, and styles.

What I Learned from the Experience

This was my first serious attempt at using an agentic AI tool for a relatively large coding project. One thing I realized is that using agentic AI is not simply about writing a prompt and waiting for the code to appear.

You still need to understand what you want to build, explain your requirements clearly, review the generated changes, and provide further instructions when necessary.

I also found that breaking a large task into smaller steps made the development process easier to manage. Instead of giving the agent complete freedom to redesign everything, I could focus on one particular part of the website at a time.

Another interesting part was using different AI tools for different purposes. I used Gemini to explore visual ideas, ChatGPT to prepare prompts and organize my requirements, and OpenCode with DeepSeek to implement the changes.

Of course, the process was not always smooth. Sometimes the model misunderstood my instructions, and sometimes I had to provide several additional prompts to get the expected result. I also encountered limitations with the free model endpoints I experimented with.

Nevertheless, it was an interesting experience and gave me a better understanding of how agentic AI can be used in software development.

The Result

After several rounds of planning, implementation, and modifications, I now have a redesigned version of my personal website.

Previously, it was mostly a minimal personal portfolio with posts and publications. Now, I have organized it into different sections so that I can publish research-related content, tutorials, essays, travel stories, teaching activities, and other personal updates.

The idea is to make it a personal archive where I can keep sharing different things over time.

There are still things I would like to improve, and I will probably continue experimenting with different AI models and tools. But for now, I am happy with the result.

It was a good opportunity to explore agentic AI in a practical setting rather than just reading or hearing about it. I am looking forward to experimenting with more tools and applying them to other projects in the future.

And finally, a little confession: this post was also written by ChatGPT and then refined by me. :D

Looks like even after using AI to build my website, I had to use AI to write about building my website!
